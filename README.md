# CALC-SIMPLE

A simple calculator project built to perform basic arithmetic operations.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Clear / reset functionality
- Simple and clean UI

## Installation

1. Clone the repository:
   ```bash
   git clone <repo-url>
   ```
2. Open the project folder in your editor:
   ```bash
   cd c:\Users\HP\Documents\IAP\website staff\port\web\project\To-Do-app\clac\CALC-SIMPLE
   ```
3. If the project uses a local server or build step, follow the project-specific instructions.

## Usage

- Open the calculator in your browser.
- Enter numbers and choose operators to perform calculations.
- Use the clear button to reset the input.
